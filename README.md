# Última Capivara

Battle royale de capivaras no navegador (three.js r128), com multiplayer entre amigos via WebRTC (PeerJS): quem cria a sala hospeda a partida no próprio navegador.

Por enquanto é um arquivo só: `index.html`. Pra rodar local, sirva a pasta (ex: `npx serve .`) e abra no navegador. `?debug` expõe `window.__uc`.

Publicado em `/lab/ultima-capivara/` no site: copiar `index.html` pra `main_website/public/lab/ultima-capivara/`.
